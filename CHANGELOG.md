# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- An Outline device: reachable, documents, collections, and the latest changed
  document (title, author, date).
- The "Outline" dashboard widget: two tiles and the eight documents changed
  last, of the whole wiki or of a collection.
- Scene trigger "Outline document created or updated" (filtered by collection
  and kind of change), silent at installation, remembered across restarts.
- Scene actions "Create an Outline document", "Add a line to an Outline
  document" (a dated journal, created at its first line in a collection) and
  "Search Outline" (the best match and the number of matches).
- Texts and documentation in English, French, German and Spanish.
